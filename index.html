2FA Live

TOTP-Codes, im Browser selbst gerechnet

100 % offline

Secrets niemals auf fremden Websites eingeben. Wer dein Secret hat, kann deine Codes für immer erzeugen — ein gestohlenes Secret ist so schlimm wie ein gestohlenes Passwort. Diese Seite rechnet alles lokal und sendet nichts; bei jeder anderen Seite musst du das selbst nachprüfen.

Rohes Base32, Name: SECRET oder otpauth://… — gemischt erlaubt. Zeilen mit # sind Notizen.

Noch nichts eingegeben. Füge oben ein Secret ein — oder klicke Demo einfügen für den Testschlüssel aus RFC 4226.

Kein Netzwerk, kein localStorage, keine Cookies. Schließt du den Tab, ist alles weg.

TOTP nach RFC 6238, HOTP nach RFC 4226, Base32 nach RFC 4648. HMAC über die Web Crypto API des Browsers.
